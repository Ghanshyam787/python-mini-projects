# 🔹 Project name - To-Do Task list

A beginner's 5th mini project of list and loop statement.
It is used in store tasks of the given date.
It is such like a notebook where you store your work details, appointmate details.
It is based on 'List data types' and voice feedback.

# 🔹 Features
- Text-to-speech voice feedback
- Add tasks dynamically
- Remember your task
- Add multiple tasks in one run
- Display all tasks at the end

## 🔹 Concept used:
- Python lists
- append() method
- insert() method
- Input / Output
- Loop statement
- if / elif codition
- voice feedback

## 🔹 How the program works

- The program asks the user to enter a task.
- The user can keep adding tasks until they choose no.
4. Finally, the program displays the complete task list.
